# Code of Conduct

We want PlanSeal to be a respectful, technically rigorous, and welcoming open
source project.

Participants must communicate constructively, respect differing experience and
backgrounds, avoid harassment and personal attacks, and handle security reports
responsibly. Maintainers may edit or remove abusive content and restrict
participation when behavior harms the community.

Report conduct concerns privately to the maintainers through the contact method
listed on their GitHub profile. Do not include vulnerability details in a
conduct report; use the process in [SECURITY.md](SECURITY.md).
